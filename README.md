# Bible de Port-Royal (Sacy) — [nouvelle édition web](https://bible.sacy.be/num/)

Version web de la *Bible de Port-Royal* (traduction de Sacy, avec le texte latin de la Vulgate et le commentaire original),
d'après les fac-similés numérisés de [bible.sacy.be](https://bible.sacy.be) (projet [sacy.be](https://www.sacy.be)).

**État : première version, Évangile de saint Luc seul** (préface, 24 chapitres, commentaire, citations en marge) avec une
**vue page à page** : le scan de chaque page imprimée en regard de sa transcription.

- Texte : transcription de l'édition imprimée (orthographe d'époque conservée), réalisée à partir des scans puis contrôlée automatiquement.
- Les images des pages sont chargées depuis `bible.sacy.be` ; elles restent la propriété de leurs auteurs (licence CC-BY-SA du projet bible-sacy).
- Ce dépôt ne contient que le site compilé (HTML statique) ; il est généré depuis un dépôt de travail séparé.

Les erreurs de transcription peuvent être signalées via les *issues* de ce dépôt (indiquer la page imprimée concernée).
